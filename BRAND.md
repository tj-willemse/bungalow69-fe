# Bungalow 69 Clifton — Brand Palette

The palette is derived from the supplied Bungalow 69 logo.

## Core colours

| Role | Name | HEX | Intended use |
|---|---|---:|---|
| Logo colour | Bungalow Sand | `#A58868` | Logo, large headings, decorative rules and icons |
| Primary dark | Clifton Umber | `#6B513B` | Buttons, links, navigation and accessible text |
| Deep neutral | Espresso | `#342A23` | Main body text and dark sections |
| Main background | Soft Cream | `#F5F0E8` | Primary website background |
| Light background | Warm Ivory | `#FCFAF6` | Cards, overlays and alternating sections |
| Border neutral | Oyster | `#DED3C5` | Borders, dividers and muted controls |

## Usage notes

- Use Soft Cream rather than pure white for the main canvas.
- Preserve Bungalow Sand as the recognisable logo colour.
- Do not use Bungalow Sand for small body text because it lacks sufficient contrast on cream.
- Use Clifton Umber for primary buttons and interactive text.
- Keep the palette restrained; property photography supplies the blue, green and sunset accents.

## Source sampling

- Dominant logo pigment sampled from the supplied JPG: approximately `#A58868`.
- Darker compressed logo pixels cluster near `#9B7B59`.
- The JPG background samples near `#FEFEFE`; Soft Cream is the intentional website adaptation.
